## Integrante

## Materia
Organización Empresarial

## Escenario elegido
Análisis de Ventas de una Pequeña Empresa

## Descripción
Este proyecto realiza un análisis básico de ventas utilizando Python.

Se calculan:
- ventas totales
- producto más vendido
- ventas por mes

También se generan gráficos y resultados almacenados en la carpeta `/resultados`.

## Estructura del proyecto

- `/datos` → datasets utilizados
- `/scripts` → scripts de análisis
- `/resultados` → gráficos y archivos generados

## Tecnologías utilizadas
- Python
- Git
- GitHub
- Jira
- Google Colab

## Ejecución

```bash
python scripts/analisis_ventas.py
```
